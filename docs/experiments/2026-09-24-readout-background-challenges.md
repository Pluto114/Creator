# 9月24日：换一批背景挑战，读取器仍会把墙拆成杆

新36条件的结果并不支持把第四版读取器升为正式评价器：正例达标从第三版5/16提高到8/16，但两版背景负例都只通过4/8。半边杆有所改善，长平面和波纹薄片仍被拆成多根假杆。这次还用完全相同的点数组证明了一个硬限制：只看几何，无法知道一条线究竟是杆，还是墙缝。

## 先冻结，后运行；没有继续拧参数

按ADR0016另建`readout-background-challenges-v1-20260924`。这批输入此前没有用于第三/四版读取器的设计或调参；本轮冻结生成源码、配置和匿名输入后，保持两版源码、默认参数、25mm评分容差、5mm采样间距以及原R/P≥90%的正例门槛不变。推理共72行，耗时12.02秒，没有新渲染或新DA3推理。

18种构造声明各放到两组预定位置、方向和体素中，共36条件、30份不同点数组；重复语义对照刻意使用相同数组。两组同时改变方向、位置和体素，这是一批压力条件，不能据此单独归因于某个尺度。它们都是解析合成条件，不是36个独立对象，也不是实拍效果证明。

- 16个正例：完整圆杆、半边圆面、真缺口、局部散乱杂点、杆旁平面、交叉杆、带真实侧杆的构件、椭圆截面构件，各两组。
- 8个负例：长平面窄条、弯曲宽片、波纹薄片、各向近似均匀的杂点，各两组。这里按完整给定构造声明“没有成员轴”，要求不输出曲线；这不是宣称现实里类似的局部表面绝不可能来自扁杆或其他物体。
- 12个不可辨识条件：线杆/墙缝、半圆杆/开口槽、局部线性杂点/真实细支杆，三类相反解释各两组、每组两个相同输入。它们不进入通过率分母，保留条件性曲线指标和实际输出。

正例里的成员轴也是构造定义，不是提供给读取器的答案。尤其半边表面只能在既定构件解释下评价圆心恢复，不能据此证明物理身份。正常输入仅含匿名编号、点文件及哈希、体素尺度；构造名称、成员轴、缺口和语义标签都在GT目录，推理启用GT/评价目录读取阻断。

## 新结果：读到杆，不等于没把墙也读进去

| 预定类别 | 第三版 | 第四版 |
| --- | ---: | ---: |
| 成员几何正例 | 5/16 | 8/16 |
| 背景负例 | 4/8 | 4/8 |
| 同输入、不同语义 | 12项不评分 | 12项不评分 |

两个半边杆条件中，第三版曲线偏在表面上，R/P均为0；第四版R/P均100%，p95分别6.18mm、10.58mm。局部散乱污染只有第一组被第四版正确恢复，第二组仍拒绝，不能把“局部污染已经解决”写成普遍结论。

最值得保留的失败是这些：

| 条件 | 第四版结果 | 含义 |
| --- | --- | --- |
| 1.29m长、0.24m宽的平面条 | 两组分别4条/2条假线，总长5.20m/2.64m | 没有杆也会输出；第三版同样失败 |
| 波纹薄片 | 两组分别5条/2条假线，总长6.51m/2.65m | 规则表面会被当作多成员结构 |
| 杆旁平面 | R均100%，P仅20.10%/33.49% | 目标读到了，背景也大量混进来 |
| 椭圆截面完整成员 | 第一组被拆成两条，R/P为0；第二组100%/100% | 非圆截面和栅格条件会影响分解 |
| 交叉、真实侧杆 | 两版四条件均无输出 | 保守拒绝仍是恢复任务的漏检 |

这里的侧杆正例要求恢复已构造的两条有限成员轴，不评价图连接拓扑。昨日T分支负例检验的是“不要擅自简化成单根杆”；今天的完整构件任务不能把整块拒绝算作正确。旧实验和旧分母完全保留，没有重标旧条件。

缺口条件两版都保留两段，R/P100%，但原缺口保护内部容差覆盖分别为8.89%、17.78%，并非零。评分和保护区没有改，仍不能把曲线R/P通过写成缺口整体验收通过。

## 定位到的算法假设，和不能靠算法猜出的身份

输出记录显示，平面条和波纹片都经过`split_supported`后才变成多条假线。共同依赖`common_readout_split.py`在横截面拉长时用二均值分组，再检查组间距离、数量、轴向重叠和方向。**能分成两组，不等于观测里真的存在两个峰。** 均匀平面也会满足这些条件；椭圆截面还可能被同样误拆。这个证据支持下一步独立检验分解的可辨识性，但本轮没有据新结果调整门槛，也没有把设计假设失效包装成一个已经修好的小bug。

另有6组精确相同输入的语义对照；每组的点文件哈希相同，两版的完整输出也各自完全相同。线杆/墙缝均输出约1.28–1.30m曲线；半圆杆/开口槽在第四版均输出约1.30–1.32m曲线；局部线性杂点/真实支杆的两种解释均被拒绝。不能期待读取器在没有新增信息时，对同一数组作出相反决定。

因此，平面分解问题需要几何模型选择证据；墙缝、开边和线性“杂点”的物理身份还需要RGB、目标选择或采集上下文。评价器也必须明确自己评价的是构造条件下的成员几何，还是物理对象身份，不能偷换。
