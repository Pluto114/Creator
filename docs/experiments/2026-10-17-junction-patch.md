# 2026-10-17：显式横向接头中线补丁

新增独立研究分支 `baseline_junction` / `junction-patch-1`：在原始 RGB 的原生杆轴两侧寻找有界横向构件，使用两侧多条剖面的中线交点，要求端外中心及邻侧已观测为背景以排除继续延伸的 X 形交叉；原生轴不变，所有检出视图须共同通过原重投影误差约束，至少 2 个独立视图。宽度只设采样距离，不再作为支持过滤或末端边界。

结论：本轮没有实质端点改善，稳定 `baseline_boundary` 保留。A 字架仅 side 0 获得 5 视图一致接头，裁去 0.646246 mm；最差端点没有变化，仍为 47.484091 mm。原生 R=100%，P=98.574822%；P 的约 3e-16 浮点变化不记为精度提升。两个 common 尺度端点误差各恶化约 0.0003 mm，也不能记为改善。其余 4 案例原生与 8 行 common 几何不变。

## 持久化与局限

- 5 个新补丁均保存 enabled/withdrawn，重新打开后核对 native geometry、基础点/ID 字节及撤回相等；没有基础点抑制。
- 原始 RGB 的 case/raw view_id 顺序一致，文件 SHA 同时匹配两处原记录；核心 SHA 还绑定原 uint8 RGB 数组。保存的补丁绑定原 rods.json、baseline 方法记录、接头上下文、策略和执行源码。
- `accepted` 只表示候选保存可用，不表示提升或 G1 验收通过。横向构件中心线是连接结构先验，不是物理端点直接观测，`physical_endpoint_observed=false`。
- 这是已见合成开发集；此前开发评分已知，不是独立采集或盲测。本轮不采用该分支替代稳定方法，没有新关闭的 G1 验收项。
- 本报告只整理已完成的单次运行产物，未再次推理或评分。
