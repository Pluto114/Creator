# 10月6日：共同单轴读取与新对象实际补丁

## 决策与边界

原metric读取器把旧fixture纯base全部读空，但同一批原始支持点的TLS在r03可恢复98.3%。本轮先替换共同读取协议做严格配对试验，再评价新对象；不修改原方法或挑选有利样例。

新增`single_axis_readout`：对原RGB支持体积内的完整base及按同一间隔采样的补丁联合处理。唯一坐标按固定世界体素聚合为均值，各体素同权TLS拟合单轴；第二/第一特征值比最多0.2、至少6体素、最短4体素。沿轴以0.5体素采样，同时满足距离占据投影不超过1体素和原RGB至少3视图投票；仅连续满足的区间输出，不做缺口闭合。端点不超出原观测投影范围。

它是预声明的局部单轴读取器，不是通用骨架或语义目标识别器。输入重复/顺序不改变拟合，但体素内采样位置仍可改变均值；小于2体素的轴向间隙不宣称可分辨。所有候选和base使用同一代码、尺度、mask与采样策略。冻结后不根据本轮结果改参数。
