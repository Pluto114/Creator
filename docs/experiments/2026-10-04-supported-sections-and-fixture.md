## 决策

不把最大内部角洞门从 30° 改为 40°。训练点负责圆模型可辨识性及参数稳定，验证点只检验固定模型的预测，完整角形态门仍作用于实际观测支持。训练固定内部窗口；有限端点属于正常观测测量，不能因首尾落在验证折就截短。

新 `common_readout_supported` / `section_supported_evidence` 不改旧冻结模块。同时新增 `FixtureSupportedReadout`，载入完整基础/保存候选后，复用旧三视图、一像素、最近原始行的 RGB 支持域，只替换共同读取器，不改变 ROI、尺度、相机或 DA3 输出。

## 解析协议

`mixed-readout-supported-v1-20261004`：旧 44/36/40 三组已评分开发回归，加独立作者构造的新 32 条件。新组为 8 族×2 体素（5.5/8.5 mm）×2 采样相位（.13/.61），固定 19 mm 步长、长度 1.45 m、seed441103、Euler[-41,26,14]°；包含有界径向噪声的完整/半面、150 mm 真缺口、正例渐变半径、真实局部角缺失、稀疏旋转弧、螺旋、薄片。

新组仅点输入，两种表示是同输入契约检查，不能增加独立证据。渐变半径仍按正例计，不因常半径模型能力不足改为负例。

608 行成对记录中，368 行实际新推理，240 行为上轮同输入同策略的 sampling 精确冻结引用。引用逐条校验输入、参数、来源哈希和结果，明确标 `frozen_parent_reference`，不冒充新执行或速度改善。全部记录核完才评分；四组分开报告，沿用同分段的有限结构展示门。

## 结果与验证

解析已冻结 121 份源、880 份 pre 收据。新增/复用的 87 项契约双 NumPy 通过（读取器 26、截面 11、构造 16、集成 6、解析 runner 14、fixture runner 14）。有限范围契约包含验证折独占首尾环、训练缺一环/连续三环、远验证段不扩测量域、真实长缺口，以及单条端部母线拒绝。

正常记录已揭示训练分折碎片回归：`replay-0021/0022/0023` 的实际连续支持仍为 1.8 m，但训练点自身被分成多个 run；完整观测 run 要求所有关联训练 run 都通过，导致整轴拒绝。`0022/0023` 的短训练碎片未达到最短 run 门；`0022` 第二组已评 18 片、`0023` 两组各已评 30 片均通过，仍受短碎片否决。`0021` 第一组 18 片中 1 片局部圆拟合返回空，另一组保留；不能将它也写成短片长度拒绝。条件数 1.41–2.62 远小于 40，测量 envelope 均覆盖完整。这不是提高 condition 阈值或放宽最大角洞能解决的问题。保留冻结源及失败，不能将分折空档等同真实物体断口。

只读复核另标出未覆盖范围：端部 collar 聚合可能让完整验证环后的孤立同半径点借用角支持；固定六轴窗不构成对任意短节距多圈螺旋的逐截面排除保证。当前声明仅限实际测试构造，后续需要独立机制契约；本轮不事后修改源。

DA3/NumPy1.26 全量 814 项通过（334.317 s）；核心 16 项/15 子检查、Ruff、296 源/三 CLI、三个 Python sdist/wheel 与 Blender 离线包通过。验证中曾误用无 NumPy 的 tools 环境跑核心测试、误用无 hatchling 的非隔离构建；改用已有 reconstruction 环境及正常隔离构建后通过，未安装或更改推理环境。
