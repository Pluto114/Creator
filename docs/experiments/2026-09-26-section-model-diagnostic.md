# 9月26日：截面有辨识信号，但残差更小还不能直接放回一根杆

本轮完成了64个新解析条件、两种点表示、两次截面参数留出，共768行模型拟合/预测记录。完整椭圆与近邻双杆在原始点里确实留下不同信号，体素中心会压弱这种差别；但半边表面、圆杆、平面和薄片都给出了反例。因此没有新增读取器、放行门槛或自动出轴，也没有把新数据上的残差排名当识别率。旧读取器及旧结果原样保留，G1状态未改变。

## 为什么不直接恢复旧圆拟合回退

只读核对[上一轮未决回放](2026-09-24-readout-abstention.md)发现：`background-0007`椭圆半轴65/27.95mm、体素18mm时，旧整体圆拟合支持率65.80%、角覆盖356°，但分隔带0/6，未决版将它完全丢掉。另一个相位、方向和31mm体素下，同一构造却被旧`single_circle_explains_cross_section`提前解释为单圆，仍保留输出；这两组同时改变多个因素，不能只归因于体素。

近邻双杆`control-0197`的旧错误整体圆拟合支持率反而达71.22%、角覆盖309°。它的真实表面间隙21mm，小于34mm体素；另两组假中轴的支持率也有57.27%、64.26%。所以再补一句“圆支持够多就恢复单轴”会把错误带回来。当前读取器先将点替换成体素中心，确实还丢掉了格子内部的位置信息。

实际DA3退步也不能省略：20/50mm容差下未决版召回与closed版逐行相同；100mm下真值相机黑白细杆粗尺度candidate从8.36%降到0，砖墙原粗杆粗尺度base/candidate从47.30%/43.96%降到0。后两项旧精确率100%/93.08%，但距离误差约8–10cm；它们不是达到25mm级恢复后又被删掉，也不能一概称无用背景。本轮没有重跑旧234/84，更没有宣称修复这些真实模型输出。

## 新实验如何配对

`section-model-diagnostic-v1-20260926`在最终输入和任何基准拟合分数产生之前冻结源码、协议和匿名输入。64条件为：八几何族 × 两档噪声 × 完整/半边支持 × 两个网格相位。它们是条件组合，不是64个独立实物。

- 几何包括圆、两种椭圆、两种间隙的双圆杆、平面窄条、折片、波纹片。椭圆与对应双圆共享外包宽高：半轴3.25v/1.5v或4v/1.5v；双圆半径1.5v、中心距3.5v或5v，即表面间隙0.5v或2v。
- v固定20mm、轴长60v；每圈64个总截面点、128个轴向位置。双圆各用32个截面点。所有条件共用固定旋转，相位只平移半个体素，不再同时换方向与分辨率。
- 噪声标准差0或0.15v。同一几何族的噪声档、裁剪和相位使用同一份随机扰动；完整/半边也是同一原始点集的固定子集。**不同几何族仍用不同随机流**，不把跨几何比较说成严格同噪声因果对照。
- “半边”是预定表面裁剪，不是完整相机遮挡仿真。输入只有匿名点文件、体素与哈希；几何族、噪声、相位和构造解释隔离在GT目录。旧16个正例没有参与门槛选择。

比较两种表示：原来的占用体素中心，以及保留格内原始位置的点。后者先精确去重，再让每个占用格总权重为1，避免高密度格凭重复采样刷票；这不是利用原图像素的置信度或噪声模型。

## 留出了什么，没有留出什么

所有点共同确定PCA方向和六个轴向片段。模型参数只在0/2/4片段拟合、到1/3/5片段预测，再交换一次。共享预处理不止方向：体素中心均值原点、5–95%轴向分位数边界、由该跨度决定的最大半径搜索上限，以及原始点表示的每格逆密度权重，都由完整输入决定。**这是完整共享预处理条件下的截面参数留出，不是完整独立验证。** 残差包含这些共同预处理的影响。

原始点按各自轴向坐标划片，所以同一个占用体素里的点还可能同时落入训练片和留出片。本轮结束后的[只读独立复查](results/2026-09-26-section-model-review.json)发现：64/64条件都有这种共享，每个条件有18–82个体素横跨两组。以冻结输入`section-0000`及对应推理记录为例，训练0/2/4、留出1/3/5时，共享58格，3648个留出点中200个所在格也含训练点。这是事后核对已有输入和边界得到的限制说明，不是新增独立观测，也不是运行前证据。

每次同时保留单椭圆、双圆和截线三种模型，分别有5、6、2个几何自由度。椭圆和双圆使用固定初值与有限次优化，留出残差以同一几何距离、同一格权重计算；所有初值结果、优化是否收敛、参数边界及数值雅可比信息都保留。模型半径边界为0.25v到轴向跨度的1/4，是事先固定的数值搜索范围，不是物理直径知识。

双圆更灵活，而且没有加入“两圆必须不相交”的物理约束；较小残差不能直接证明两根独立杆。椭圆可能以很扁的形状解释薄片，半面也可能同时符合多种补全。未观测到点不能被当成测得的自由空间，封闭性也没有被这次诊断证明。没有采用似然比、置信区间或“残差小于某值就通过”的规则。

## 已观察到的信号与反例

下表为**完整支持、保留格内位置**的留出RMSE中位数，单位为v。每行合并两档噪声、两相位、两fold，共8个相关比较；不是8个独立验证样本，不能据此估计总体成功率。

| 几何族 | 单椭圆 | 双圆 | 截线 |
| --- | ---: | ---: | ---: |
| 圆杆 | 0.091 | 0.061 | 1.941 |
| 椭圆，对应窄间隙外包尺寸 | 0.091 | 0.235 | 1.157 |
| 椭圆，对应宽间隙外包尺寸 | 0.092 | 0.334 | 1.170 |
| 窄间隙双圆杆 | 0.430 | 0.097 | 1.097 |
| 宽间隙双圆杆 | 0.466 | 0.091 | 1.073 |
| 平面窄条 | 0.064 | 0.097 | 0.086 |
| 折片 | 0.245 | 0.107 | 0.483 |
| 波纹片 | 0.434 | 0.452 | 0.905 |

完整的两类椭圆在各自8个比较里，椭圆残差均小于双圆；完整的两类双杆反向也一致。这支持继续研究截面预测，而不是只盯横向密度。但只看这一半就会被骗：圆杆也更偏向灵活的双圆，平面和波纹片会偏向椭圆，折片会偏向双圆。没有任何一个排名被转换为“认对了杆”。

半边表面进一步削弱区分：两类半椭圆在体素中心表示下，全部8/8比较都更偏向双圆；保留格内位置后，各只有4/8比较更偏向椭圆。两类半双杆在原始点表示下仍全部更偏向双圆，但在体素中心下变成仅5/8、4/8更偏向双圆。部分表面的不确定性不能靠把完整表面的规则直接套过去解决。

保留格内位置值得追踪：窄外包椭圆的完整支持中，椭圆相对双圆的残差优势，从体素中心约0.03–0.05v扩大到原始位置约0.09–0.20v；窄间隙双杆的双圆优势也扩大。但这只说明本批输入包含被体素化压弱的证据，不证明DA3点云有同样清晰的截面，更不授权缩小旧读取器的体素或阈值。

768次模型拟合全部留下记录。双圆256次中14次未在固定预算内收敛；椭圆69次、双圆27次触及参数边界，主要集中在平面/薄片，也包括部分真椭圆及双杆。它们仍计入上表和完整JSON，不能只挑收敛漂亮的条件。数值雅可比未被机器精度判据标成降秩，也不等于参数有可靠不确定性界。
