# 六组细杆先导实验：2026-09-14
> 后续场景核对：原场景已经提供并备份。旧文的 0.01 / 0.05 / 0.12 是历史尺寸标签；可重现图像的实际直径为 0.02 / 0.10 / 0.24。几何与相机已导出，真实深度和掩码仍待导出。详见 [原场景核对记录](2026-09-14-source-scene-verification.md)。下文保留首次实验时的条件和限制。

本轮已完成六组 DA3 LARGE-1.1 推理和一组更高分辨率对照，没有实现或评测 Creator 修复算法。发现的主要现象是：砖块背景最细杆的原始预测存在几何不稳定，默认置信过滤又大量移除其对应点；黑白背景则连粗杆之间的空隙也被预测为连续近表面，属于需要单列的整体分离问题。

## 输入与固定条件

- 实际输入：`D:/Creator-newage/.runtime/inputs/test_pack`，30 张 1920×1080 PNG，RGBA 且 alpha 完全不透明。
- 六目录的 thinner / origin / thicker 暂按用户给定三档对应直径 0.01 / 0.05 / 0.12。尺寸和单位未由场景文件核实；原目录拼写保留。
- 每组按 −30°、−15°、0°、15°、30°排序输入。这些是文件名角度标签，不是已知相机外参。
- 每张图包含五根连续杆，以及最右侧本来就有中段缺口的杆；原始缺口不计为模型断裂。
- 主实验：DA3-LARGE-1.1，权重 revision `0e109ae307c5982f319a67cf6f9f99ccdc0ec97c`；上游 commit `3d835ec1a5802d64a8b8b15f817a1ab54809bfe4`；长边 504，实际 504×280；5 视图；`use_ray_pose=false`；`ref_view_strategy=saddle_balanced`。
- 全部模型与数据留在本机 D 盘。浏览器默认最多采样 10 万点，仅用于显示。诊断图的点云由全部原始深度反投影，在过滤前后分别绘制，不使用浏览器的随机子样本。

## 首轮观察

| 背景 | 直径标记 | 定性观察 |
|---|---:|---|
| 黑白 | 0.01 | 上半部杆间大片区域被预测为连续近表面；细杆几何较差 |
| 黑白 | 0.05 | 同样有杆间背景被并入前景的问题 |
| 黑白 | 0.12 | 粗杆仍出现上半部背景误分离，不能当纯细杆问题 |
| 砖块 | 0.01 | 深度沿杆高度不稳定；未过滤点云呈弯曲、重影；默认过滤后杆大幅消失 |
| 砖块 | 0.05 | 杆在深度中更清楚；融合后仍见局部不连续/变形 |
| 砖块 | 0.12 | 分离出的杆形更清楚，0°深度图保留右侧原有缺口；尚无三维准确性指标 |

砖块组同时改变墙与地面的外观及局部亮度/对比，不能把两类背景的差异全部归因为“纹理复杂度”。同一资产的六个条件不是六个独立物体，不构成泛化测试。

## 分辨率与过滤对照

在首轮观察后，追加砖块背景最细组的 756×420 推理，五张原图及其顺序、模型和其他推理参数相同。这是开发阶段的针对性诊断，不是预注册的独立测试。

| 条件 | 504×280 | 756×420 |
|---|---:|---:|
| 原始像素/点数（五视图） | 705600 | 1587600 |
| 默认过滤阈值 | 12.1165 | 8.3126 |
| 默认过滤保留点数 | 423360 | 952560 |
| 固定阈值 1.05 保留点数 | 705149 | 1585831 |
| GPU peak allocated | 3590.6 MiB | 5371.8 MiB |

默认导出采用全局置信度第 40 百分位并设下限；本包六组实际均保留 60% 的点。相同过滤规则不意味着每组绝对阈值相同，点数保留比例不代表准确率。

提高分辨率后，0°深度中的细线更连贯，但从偏转角度观察全部反投影点，杆仍弯曲并有重影。固定阈值 1.05 使杆重新可见，同时保留更多错误几何和背景噪声；它不是几何修复。默认过滤导致杆进一步消失，两种现象不能混为一种“模型没预测杆”。

作为图像位置诊断，在 0°图五根连续杆的上部手工规定搜索带，逐行取 RGB 亮度峰值，并检查这些像素的置信度。504 下得到 380 个样本，756 下 570 个；本次这些样本均未通过默认阈值，约 95.3% / 93.5% 通过 1.05。该统计只描述指定图像位置的过滤行为：不是完整杆掩码、不是三维真值，也不是恢复率。搜索规则与逐像素记录已保存到分析脚本和 JSON，不能外推到全部杆像素或全部视图。

## 已验证与未验证

已核对输入 SHA-256、六组演示复用 NPZ 的哈希、输出形状、有限数值、正深度和资源链接。自己相机的反投影/回投最大误差约 0.000024 像素以内，只证明几何转换自洽，不证明预测正确。七次模型推理均成功。

静态总览、代表案例和过滤对照图已实际查看；由于本地网页访问受工具策略限制，未进行浏览器交互视觉验收。图中用 3×3 像素点斑使离散点可见，不推断连续曲面。深度配色按组归一化，不能跨组按颜色比较距离。

包内没有 .blend、真实深度、杆掩码或完整相机参数，因此暂不报告三维误差、中心线恢复率或错误连接率。最薄档在模型输入中接近一两个像素的亮线，需要继续做同信息、同资源口径的局部裁剪等简单对照；本轮尚未完成局部裁剪、已知相机诊断、独立重复运行或真实物体复核。
