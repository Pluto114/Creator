# 全视图保留观测审计：补上端视角，但不能把亚像素误差当三维合格

日期：2026-09-23。状态：完成，补充诊断，不改变主方法、旧分数或候选门。

原相机验证会选轨迹中初始相机基线最长的两张图三角化，再对其余图打分。这个规则没有把评分像素塞进三角化，隔离本身是对的；但本次七组数据中，最左、最右两个视图始终只参加三角化，**在原验证分数里一次也没单独被打过分**。这不等于这两个相机完全没有约束，但逐视图覆盖确实缺了一块。

本轮追加独立的`camera-all-view-validation-v1-20260923r2`。每条原验证轨迹的每个观测轮流留出，其余观测按**初始相机**选择最大基线的两张图。先冻结所有配对及相机输入，再对初始、普通、鲁棒、两阶段相机重复评分。既不重新拟合相机，也不用GT；旧主评分和门控保持原样。

范围包含同高度参考路径r01–r04（含变焦反例）和高度变化路径r01–r03，合计7组、28个数值相机条件。377条原验证轨迹提供1,352个不同的被评分观测，四个相机条件共5,408条残差，其中1,700条是此前不单独评分的两个端视角。**这不是5,408个独立样本**：同一轨迹的多行残差互相依赖，同一观测又在四个相机条件中重复使用。

有符号残差揭示了细杆数据里中间视角v方向偏负、两端偏正的结构，可用于下一步相机敏感性诊断。现在还不能说它就是杆偏移的原因：验证特征集中在图像上方、杆外侧；这些背景点的误差还混合了特征测量误差、三角化基线及相机误差。

最关键的负结果是：**把所有视图都检查了，细杆仍能在亚像素残差下产生明显的三维偏差。** 旧评价中高度变化细杆曲线p95约30.35mm，而这里只读RGB诊断的p95约0.677px。两者并列说明不能把像素一致性直接当物理精度，不能为了抓住这根杆而事后硬塞一个更严的像素阈值。这里对既有物理评价的引用只是事后解释，GT没有进入新计划或评分。

## 如何继续，哪些结论先别下

这次用很小的工作量补齐了覆盖审计，尚未修复算法。下一步可以在新版本中对训练轨迹做事先固定的分组扰动/留组重拟合，保持这里的验证计划不变，查看相机、杆三维曲线及候选身份是否对同一批RGB证据敏感；先报告分布，不凭GT挑一个“最好”的结果。若重新拟合后背景残差很接近而杆位置明显漂移，就该优先处理可观测性和不确定性，不能只加端点规则。

另一个已确认的限制：两条细杆路径的杆关联都只有0/1/3/4视图支持，+3°没有图像线候选。全视图背景验证增加了这个视角的评分，但不会凭空给它补出杆像素证据。候选稳定性仍须另外检查。
