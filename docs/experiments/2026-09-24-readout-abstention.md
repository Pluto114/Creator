# 9月24日：看不清几根，就别硬画一根中轴

这轮把上次暴露的危险回退拿掉了：已有二分提议、却缺少持续分隔带的组件，现在明确标为未决，不再整体拟合一根轴。两条错误中轴消失了，但真杆也多漏了一项。**这是减少错误声明的一步，不是恢复能力已经达标，更不是G1通过。** 本轮只冻结并回放一个版本，没有看到成绩后再调门槛。

## 固定规则与接口

新模块`common_readout_abstention.py`直接复用上一轮closed版本的全部默认参数和`guarded_split_component`。分隔带宽度、密度比例、六段检查、四段通过等阈值一项没动。

有效旧二分提议被分隔带否决时，该组件不输出曲线，保留未决原因、稳定组件路径、递归深度、体素数、包围边界、完整分隔带证据及两种未采用的解释。其他独立组件继续处理；一块看不清的背景不能把旁边能读到的杆一起抹掉。达到原拆分深度上限时也检查提议，有提议却无法继续拆同样标成未决；只有没有有效二分提议的组件才沿用原来的整体圆/线检查。

顶层`state=complete`仍只表示执行完成，评分继续照常跑；新增`resolution_state`和`unresolved_component_count`/`unresolved_components`表达几何决策：

| 状态 | 含义 |
| --- | --- |
| `resolved` | 有输出，且没有本轮定义的二分未决；不保证轴正确，也不证明物理身份 |
| `partial` | 保留已有曲线，同时存在未决组件；整体仍不完整 |
| `unresolved` | 存在未决组件，且没有可保留曲线 |
| `no_supported_curve` | 没有输出，也没有这一类二分未决；可能是原有拒绝/漏检，不能直接解释成背景 |

这里的状态只覆盖本轮二分歧义，不是把所有几何失败都重新分类。没有把未决组件的候选假设输出成正式轴，也没有改旧的曲线评分和通过门槛。
