# 冲刺候选审计：先确认解释完整，再谈谁排第一

2026-09-23。**本轮没有找到能替换默认杆算法的赢家。** 新增固定像素赋值重拟合与三项对照，查明旧“唯一候选”会隐藏近邻的不同观测解释；简单重排仍未改善细杆，且让新断杆退回不确定。保留旧默认、所有失败和全部新结果，G1未通过。

## 先把失败原因说准确

上一轮高度变化断杆在全真实相机时，状态名为`competing_or_partially_supported_identity`。逐项重放发现，旧流程实际只保留一个候选；其−32°视角选中的第3号图像线只覆盖y=166–381，没有点击所在的y=135行。+19°点击有支持，但两视图身份要求缺一不可，因此只是部分支持，不能把状态名直接解释成两个物体竞争。

候选0在同视图有247行、覆盖y=82–381，含点击行；候选3只有161行。旧真实相机赢家的五视图赋值是(3,2,0,0,0)，估计相机的旧赢家是(0,0,0,0,0)。它们的差别不仅是轴位置，还包括哪些原始边缘行有资格支持有限段和身份。

这里不能倒过来拿GT挑候选。全五视图重拟合后，旧真实相机赢家像素中位误差0.2204px，00000为0.3111px，前者仍更低，两者都低于原1.5px门槛。有效支持行总数分别1074和1247，更多行也不自动证明正确：长背景线和短遮挡目标就是反例。

圆柱拒绝也定位到了实际阶段。例如高度变化完整杆的相同像素赋值，首轮有四个视角通过，+35°退出；用余下四图重拟合后，+19°右侧只有67.79%边缘在1px以内，未达到原90%要求，故最终拒绝。不是输出文件丢了，也不能靠跳过最后复核救回来。

## 冻结三项对照，原观测和阈值不动

新`rod_assignment_refit.py`复用原三视图种子与最近候选匹配检索。不同种子产生同一固定支持视图/候选赋值时只重拟合一次，用所有这些支持视图重新拟合，然后逐一检查同一组候选残差；超阈整项拒绝，不偷换像素，也不删掉坏视图再冒充通过。

预先指定`refit_residual`为最小改动主对照，其余两项为开发诊断：

| 变体 | 排序与保留 |
| --- | --- |
| refit_residual | 支持视图数、最终模型残差；沿用旧投影去重和歧义间距 |
| refit_coverage | 视图数、各视图相对行支持比例的中位数、最终残差；仍沿用旧保留规则 |
| retained_assignments | 同一最终残差排序，但保留同等级的不同像素赋值，不按投影距离删掉它们 |

中位行覆盖仍可能掩盖少数视图缺证据，本轮前两种排序给出的最终状态和指标完全相同，不能说行覆盖已解决问题。第三项会更诚实地暴露解释不唯一，也可能过度保守；26个候选解释不代表场景里有26根杆。

“完整检索”范围也要收紧：这里只完成当前候选上限和最近匹配种子枚举。0.9相对支持比例仍会在五视图解释存在时排除四视图解释；同线并列的最近匹配仍优先第一项。因此不能宣称穷尽了所有物理可能。

正常运行`rod-assignment-refit-v1-20260923r3`覆盖两种路径共7条件（含变焦）、初始/两阶段两种相机，共14相机任务。每项三变体×普通/圆柱两方法=84行新结果，加28行旧方法配对，共112行。点击、RGB池、相机、有限段规则和25mm评价容差均不变，正常推理启用真值误读阻断，没有新增模型预测。

## 正常结果：不把拒绝数变化说成恢复成功

下表为两阶段相机、普通杆方法。相同行的R/P是有限曲线诊断，不是点云恢复率。

| 已知场景 | 旧方法 | refit_residual / refit_coverage | retained_assignments |
| --- | --- | --- | --- |
| 同高度完整杆 | 接受，100%/100% | 接受，100%/100% | 45候选，未决 |
| 同高度断杆 | 接受，82.30%/84.05% | 相同 | 36候选，未决 |
| 同高度细杆 | 接受，67.60%/68.30% | 相同 | 5候选，仍接受同一错误结果 |
| 变焦反例 | 拒绝 | 拒绝 | 14候选，未决；相机本身仍扣留 |
| 高度变化完整杆 | 接受，100%/100% | 相同 | 34候选，未决 |
| 高度变化断杆 | 接受，100%/100% | 一个部分支持候选，未决 | 26候选，未决 |
| 高度变化细杆 | 接受，69.40%/70.46% | 相同 | 5候选，仍接受同一错误结果 |

高度变化断杆的新重拟合赢家变成(3,2,0,0,0)，因此重现缺点击行的问题。保留赋值版并没有丢掉00000，但26项中有7项前景支持、3项部分支持，其余几何拒绝，现有两次点击不能证明唯一。这使上一轮100%曲线分数的解释更谨慎：那是某个输出的几何分数，不是目标身份和候选唯一性的完整保证；原分数和输出没有被改写。

包含初始相机和圆柱法的28行/变体，旧方法接受10、拒绝18；主重拟合和行覆盖均接受9、拒绝18、未决1；保留赋值版接受5、拒绝16、未决7。**这些是状态计数，不是正确数。** 两条路径的细杆错误接受仍然存在；保守版也拒绝了正确完整杆。所有初始相机仍无输出，扣留相机的诊断不进入可用补丁。
