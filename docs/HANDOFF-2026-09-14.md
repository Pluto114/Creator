### 5.3 关键结论，必须准确表述

1. **黑白背景有整体分离失败。** 连粗杆上半部之间的空隙也被预测为连续近表面，不能把它算作只有细杆断裂的干净证据。砖块组同时改变墙、地面外观及局部对比度，不是完全单变量的纹理对照。
2. **砖块背景内，细杆比粗杆的预测更不稳定。** 最细档未过滤点云中能找到杆，但明显弯曲、重影。中/粗杆的分离更清楚，仍未用真值证明几何准确。
3. **默认置信过滤进一步删掉杆。** 此包默认第40百分位过滤均保留总点数60%；实际阈值随组变化。砖块最细 504 阈值约12.1165，756约8.3126。改为1.05可保留更多杆点，同时保留错误几何和噪声，不是修复。
4. **756 没有消除上述问题。** 0°深度的细线更连贯，但合并后的弯曲、重影仍在，默认过滤后杆仍大量消失。尚未完成局部裁剪或真实相机对照，不宣称已排除所有简单办法。
5. **不存在正式恢复率或已成功的自研算法。** 图像亮度峰值抽查只是过滤诊断：0°五根杆上部504下380个、756下570个样本均未通过默认阈值。95.3% / 93.5%通过1.05不是恢复准确率，不能这样宣传。
6. 同一资产的六种条件不是六个独立对象；后续需要独立物体才能评估泛化。

更完整证据见 `docs/experiments/2026-09-14-thin-rod-pilot.md`。

- 杆是 `Cylinder*`，X/Y缩放对应三档；五根整杆高4，两段缺口杆各长1.8，具体端点从导出记录读取。
- 墙 `Plane` 对应 `Material.002`，地面 `Plane.001` 对应 `Material.003`。接通两材质的 Brick Texture.Color → Principled BSDF.Base Color 得砖块组；断开链接并使用保留的原默认值即可重现黑白组。不要擅自换纯白/纯黑材质猜测原设置。
- **Cylinder.003 与 Cylinder.002 的世界顶点集合完全重复。** 已标记 duplicate_geometry_of。原场景未删除此对象；评测去重，不能把相同物理杆计两次。
- 没有外部贴图缺失，不需要用户提供其他文件。

### 6.1 已导出的真实几何和相机

**`data/eval_gt/thin-pack-v1/`**：

- `geometry_cameras.json`：六条件各杆中心线端点、实际尺寸、重复映射、30个相机、输入哈希和原图匹配标志。
- `render_verification.json`：全部30张逐像素比较。
- `verification_summary.json`：汇总。
- `README.md`：使用边界。

相机投影与 Blender `world_to_camera_view` 对照最大偏差约 **0.000114像素**，只是几何导出转换校验。

- 黑白厚杆−30°：完全一致像素99.9866%，平均通道差约0.000114/255，最大5/255。
- 砖块厚杆−30°：完全一致像素99.9267%，平均通道差约0.000316/255，最大5/255。

## 7. 新聊天直接开始的目标

用户已经同意沿研究方向继续。**新聊天优先完成可量化的实验闭环，不先扩建插件界面。**

### 第一阶段：补齐并验证带真值的数据包（立即开始）

1. 读上述核对报告、`geometry_cameras.json` 与 `freeze_source_geometry.py`，复用已确认参数，不手动重建场景。
2. 设计可重复运行的小型导出入口，成组输出严格对应的RGB、真实深度、每根杆的ID/可见掩码、相机、真实中心线和缺口标签。输入与评测真值隔离保存。
3. 原场景/旧图片/旧结果保持可追溯。新渲染成套版本显式命名，保存配置、版本和哈希；不要静默覆盖六组原包。
4. 校验 Blender 深度输出究竟是相机Z深度还是沿射线距离，再与DA3约定匹配。不要靠猜测套公式。
5. 校验抗锯齿边缘、亚像素细杆、遮挡、背景无命中，以及RGB/depth/mask的像素对应。物体掩码不能从“图上亮不亮”冒充几何GT；不能把阴影或砖缝当杆。
6. DA3的504×280/756×420存在实际预处理变换；原图GT变到模型尺寸需要正确映射、可见性和采样约定，不能随意对深度/实例标签双线性插值后当真值。
7. 用已知平面或杆的可核对样本做必要几何检查，并实际看几张图再宣布数据包成功。

此阶段验收：能够一次命令重现指定条件并导出可信、同步、可追踪的输入与真值；清楚报告特殊像素和不可评区域。先完成小样例再批量30张，不必先实现所有正式模块。

### 第二阶段：量化基线及简单对照

- 原始DA3深度、未过滤点云、默认过滤、固定较低阈值分别评估，避免把导出行为算成模型预测能力。
- 正常估计相机作为主实验；给真实相机的运行单独标为诊断/`oracle_camera`，不能混成公平主线结果。
- 先明确全局尺度/坐标对齐，不能用待修杆本身做事后最佳ICP来隐藏误差；复用架构文档中的对齐约定。
- 指标覆盖可见杆的位置偏差、完整性/缺失、错误新增/错误连接，保护原有缺口，并保留失败案例。
- 点云表面与中心线不是相同表示，不能用偏袒新曲线的读出器人为丢掉基线杆。参照05评估规格，先验证小范围指标实现。
- 完成同输入信息下的高分辨率、局部裁剪、简单直线拟合对照及资源记录，判断复杂方法是否必要。

### 第三阶段：最小实际修复

只先做一根直杆：人工ROI→多视图杆状观测→对应/三角化或拟合→证据检查→三维中心线→局部前后对照。保留原始基底，支持拒绝/不修改，不能靠把所有断点连起来得高分。

此阶段验收：在不同对象上出现可重复的几何改善，同时报告误补全和成本；只有漂亮图、单例手动补线或阈值调整不算通过。
