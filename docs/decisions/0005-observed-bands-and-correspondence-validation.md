# ADR 0005：亮暗条带先作为观测假设，不能直接升级为物理轴线

日期：2026-09-17。状态：接受为后续实现与验收方向；本次没有发布新的普通照片修复算法。

## 依据

[9月17日诊断](../experiments/2026-09-17-center-and-correspondence-audit.md)将昨日两个失败拆开了：

- 中杆几何轮廓中点和真实轴偏差最多0.00728 px，检测中心却偏3–8 px；被选边缘通常只包住一部分亮条。
- 相同几何/相机/检测器，在目标表面改为均匀亮度后，共同选中行的误差从2.6–8.1 px降到0.12–0.16 px。外观响应是已验证的失败来源。
- 简单的候选中心分歧拒绝规则可挡掉一部分线性/阶跃亮度造成的错误，却挡不住唯一且稳定的偏置亮条，也没有恢复出正确中心。
- 砖块图的原始ORB/SIFT匹配，双向可评部分只有约15–18%是2 px内物理对应。验证集F自洽仍可能建立在重复结构的错误对应上。

## 决定

1. **把图像亮暗条带和物理中心线分开。** 检测器输出边缘、亮度剖面、宽度、候选与未知；物理轴的位置需要额外几何/轮廓证据。当前中心点不应直接充当已确定的测量。新类型或正式契约尚未实现，不能只改字段名就宣称问题解决。
2. **保留多种解释，禁止强制选最宽边缘。** 宽轮廓可能包住两个物体或背景纹理，窄亮条又可能来自杆表面。下一版要在多个视图中同时解释边界、可见范围和候选几何，测试几何中心是否可辨识；不能靠单视图最大对比或最外边缘拍板。
3. **平坦样观测继续是未知原因的假设。** 低对比真实杆也能形成这种响应。没有额外可见性/对比证据时，不将其当作必须切断的物理空白。
4. **先验证背景对应，再允许共享相机优化。** 后续考虑跨三视图轨迹、回环、局部外观和独立验证对应，检查重复结构与平面退化。相机评价保留完全独立真值；目标杆和GT不参与相机拟合。
5. **效果和拒绝都要计账。** 正确恢复量、错误新增、端点、缺口、未知比例和误拒同时报告。中心偶然正确但轮廓错误、拒绝全部候选、缺口不被碰到但杆整体偏位，都不能算通过。

## 下一轮可验收的工程

先在今天固定的22类解析剖面上比较观测策略，要求在亮条、背景纹理、低对比和真缺口上明确暴露不确定性；改善准确率时不得隐藏接受量下降。之后冻结候选方法，在新增几何布局及有/无重复纹理的场景验证多视图边界解释和背景轨迹。

9月16日新视角已看过，今后只作开发回归；新方法的验收需要新的冻结场景或视角。通过这些检查，再接正式局部补丁和共同曲线读取器。插件界面、真实半径恢复与自动完整拓扑继续延后。

## 本轮没有改变什么

旧检测器、旧模型预测、旧相机和旧评分均保留。新增的是诊断工具、受控实验及一个明确失败的保守规则对照。项目仍在G0，跨对象收益与普通照片恢复尚未证明。
