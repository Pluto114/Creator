# ADR 0017：把相机扰动传播到有限杆，二分必须有分隔证据

日期：2026-09-24。状态：采纳下一步方法设计；尚不替换默认方法或G1验收口径。

相同原图候选、相同全部支持像素下，固定背景轨迹留组使两条已知细杆恢复率分别落在0–100%和6.7–99.3%，而全视图背景p95仍约0.6–0.9px。原生坐标中的有限段也发生位移，不能仅解释为GT评价对齐变化。新背景挑战又表明，旧读取器能把均匀平面切成多根假杆，几何相同的杆/墙缝也不可能仅凭点数组区分身份。

1. 相机候选通过像素门不等于杆可信。下一版应保留当前完整训练作为主估计，在固定像素赋值下传播K/E扰动，报告有限段位置、方向和端部变化。四组结果只作敏感性证据，不冒充已校准置信区间、不用GT选fold、不平均后替代主结果。当前实验同时改变K/E，不能声称已经隔离位姿贡献。
2. 接受/拒绝的不确定性必须作为结果保留。相机扣留时杆局部算法仍可能误收，因此不得跳过相机层发布补丁。先在新的几何和采集条件上冻结不确定性规则，再验证收益与拒绝代价。
3. 读取器不能凭二均值可分就宣称存在两根杆。独立修复候选为旧二分增加跨轴向片段持续的、分辨率可辨的低密度分隔证据；失败时回到完整组件的圆/线检查。参数在回放前一次冻结，专项检查平面、真双杆、圆/半圆及网格边界。真实模型结果必须一起报告，不能只挑解析控制。实测边界修正版新负例4/8→7/8，但旧控制197/198→194/198，两组真双杆回退成假中轴；因此该修复也不推广。下一版不能把“二分证据不足”直接变成“单杆成立”，应保留未决解释并独立验证。
4. 同输入相反语义的条件单列不可辨识，不混入通过率。成员几何和物理身份分别说明；身份需要RGB、用户目标或采集上下文，GT语义不能进入读取器。
5. 9月24日新挑战既已看到结果，后续修复回放一律作为开发集。旧198控制、真实DA3结果、原缺口指标与所有失败版本完整保留。此次未新增独立物体、实拍、深度基础或自动补丁。

G1仍未通过。相机敏感性与读取器反例已经有直接证据，接下来工作不是继续扩大同类回放数量，而是形成可验证的保守规则并取得独立对象证据。9月27日仍作为检查点，不降低门槛换取按时“完成”。
