# ADR 0012：相机校正先过观测入口，保留正对照与失败分支

日期：2026-09-22。状态：采纳实验顺序；相机优化器尚未实现。

## 依据

同输入ray pose对照没有正确杆，普通错误接受从2变3，尽管相机中心RMSE更小。当前砖墙图的SIFT完整轨迹大多物理对应正确，但关键侧视图只剩1–2条；ORB闭环仍大量跟错砖块。当前数据不支持直接把背景匹配用于可靠校正。

解析RGB正对照发现“共享任意格子就合组”的验证划分会被密集轨迹连成巨组。新固定图像带划分恢复独立训练/验证，同时保持全部匹配图、物理评分不变；独特双深度SIFT通过数量和非平面前置检查，单平面及重复纹理未通过。正例仍有错误轨迹，入口不是正确性证书。

详见[实验报告](../experiments/2026-09-22-camera-heads-and-track-availability.md)。

## 决定

1. 暂不采用ray pose替代当前默认分支；保留新预测和错误补丁作配对回归，不按真值逐目标挑分支。
2. 相机优化先要求多视图轨迹数量、所有视图覆盖、训练/验证空间隔离和非平面证据。当前杆图标为观测不足，不强行输出校正。
3. 下一实验先在独特双深度正对照检验鲁棒优化，再测试具备对应支持的杆场景。必须带错配、原相机和未优化对照，评价只读保留结果，不将GT放进优化器。
4. 参考纹理、额外拍摄或人工对应都属于输入/采集预算变化，不能伪装成同输入算法增益。当前闭环仍缺独立资产和共同读取器资格，不降低G1标准。

这项决定承接ADR0011的位姿优先级，补上“可以用什么观测校正”的前置条件，不代表校正算法已经有效。
