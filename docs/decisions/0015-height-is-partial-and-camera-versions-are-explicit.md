# ADR 0015：高度变化只解决部分问题，相机版本必须带着点云一起变

日期：2026-09-23。状态：采纳；补充ADR0014的适用边界，未批准自动应用。

冻结高度干预在断杆上将普通曲线R/P从82%/84%提高到100%/100%，但缺口保护区仍有2.65%容差覆盖。细杆未达标，完整杆/断杆圆柱法退回拒绝，相机中心RMSE三组都稍差。全真实相机诊断中新断杆仍因候选身份歧义拒绝，因此不能继续把所有失败归给相机位姿。

1. 保留高度变化为采集对照，不宣布默认路径更优。继续固定主两阶段方法、全部比较分支、25mm容差和缺口保护区。
2. 下一轮先审计冻结像素池的候选保留、身份支持与视角退出，对比新旧路径。真实相机仅定位问题；不拿特权成功替代正常收益，不放宽门槛赶日期。
3. 相机变化时重新反投影原生深度，创建明确的新几何身份。新基础记录深度内容、相机、原预测与帧来源，旧补丁不得跨版本应用。
4. 深度保持原值的重投影只完成工程版本集成，不是深度修复。当前0.1点协议加来源侧文件不冒充完整正式深度契约；共同读取器未合格，禁止声称点云净收益。
5. 正常推理与GT替换分开保存；只生成预先指定的初始/两阶段研究快照，扣留相机不生成候选版本。所有历史输出保留。
6. 三种已知圆柱布局不是独立对象，G1仍未通过。后续还必须完成共同评分与独立对象验证。
