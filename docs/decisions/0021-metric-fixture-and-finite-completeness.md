# ADR 0021：已知尺寸采集提供正例，有限结构仍需完整验收

日期：2026-09-27。状态：采纳下一批验证方向；G1未通过，正常默认方法不变。

## 今天得到的证据

新增双深度、已声明CAD尺寸的标定物，RGB独立估K与位姿，旧有限杆参数保持不变。三个旧杆布局、每组五图、两种方法共六行全部输出；直接CAD米制坐标下，完整杆与真实断杆轴线p95约1.5–3.2mm，断杆保护后的300mm缺口零误填。0.01直径细杆也给出接近真实轴的线段。这支持继续研究明确标定条件下的局部有限结构恢复。

它不证明对任意照片、真实制作误差、畸变镜头或独立物体有效。相机中心仍偏8.2–12.3mm；本轮同时改变参考物和RGB，不是仅替换相机算法的单因素比较。没有新增DA3点云及完整候选评分，经典标定与几何组件本身也不作为研究创新。

## 新暴露的问题

最细杆输出两段，比真值少39.631mm，其中19.219mm是假断口；预测边界4个，真实只有2个。25mm容差R/P仍都100%、p95只有0.084mm，因为小缺口可被邻域覆盖，少于5%的局部错误又会躲过95分位。

细杆view_02没有合格图像候选，所有case的view_04池都截到8条。因而“相机通过”“曲线p95很小”“保留池搜索完成”都不能单独证明结构完整或候选唯一。

## 下一批怎么做

先冻结同一标定条件下的细杆观测诊断，解释为什么一张图没有候选、为什么顶端附近丢连续支持；再设计真实小缺口、完整细杆、低对比、近邻线和遮挡的成对控制。允许检验亚像素/模糊轮廓模型，但不直接降低最小宽度或合并短缺口来消掉今天的失败。对不可分辨的真缺口保持未知，错误桥接代价与恢复率并列。

针对标定条件，加入板尺寸/位置测量误差、相机畸变和不完整标记的预声明挑战；留出标记ID不能发现所有共享比例偏差。需要相机方法对照时在同批RGB上单独冻结，今天已评分数据归为开发材料。

有限结构验收继续并列长度、边界数、端点和真实缺口，禁止用更宽的容差或一个p95替代。之后仍须完成合格共同读取器、同来源相机/深度的完整基础与补丁、未参与设计的对象及实拍。不能把今天的漂亮细轴直接当成原始点云已经修复。
