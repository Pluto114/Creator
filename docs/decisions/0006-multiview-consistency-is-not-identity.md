# ADR 0006：多视图一致用于关联候选，不单独证明物理身份

日期：2026-09-19。状态：接受为下一版候选关联设计；尚未发布正式修复算法。

## 依据

[冻结的12例多视图机制测试](../experiments/2026-09-19-multiview-candidate-association.md)表明：

- 真实斜杆和带各视图独立杂纹的真杆可以正确交会，说明保留多候选再跨视图验证值得继续。
- 两条跨视图都一致的线会被保留为歧义，没有按真值或最近距离强选。
- 四视图门槛能拒绝各视图位置不一致的假条纹；三视图门槛可能把任意三条线凑成假三维解释。
- 四视图门槛也会拒绝只在三张图中可见的真杆，不能作为无条件硬规则。
- 跨五视图一致的表面亮条会以0.075 m偏差被错误接受；空场景中一致的背景线也会被两个变体当成物体。几何一致没有提供目标身份或物理轴证据。

## 决定

1. 多视图模块输出`geometrically_consistent`、`ambiguous`或`rejected`候选，不直接输出“已恢复物理杆”。
2. 所有得到接近支持的分离三维线都进入替代假设；不得按GT、最近旧点云或固定最左/最宽规则暗中挑选。
3. 支持视图数与独立可观测性分开记录。至少四视图可作为抗不一致杂纹的强证据，但不设为全局硬门槛；不可观测性需要独立判断。
4. 正式接受还需身份证据。下一轮优先测试多视图外轮廓/宽度与视角相关表面响应；如果输入不能区分一致背景线和目标杆，返回歧义或需要人工对应。
5. 无限线关联不推断端点、缺口或拓扑。身份层通过之后，有限范围仍由逐段正反证据决定。

## 代价与验收

候选数量和组合开销会上升，本轮12例推理约需数分钟，后续要用分层剪枝代替无界枚举。剪枝只能使用方法侧残差、相机与观测属性，不能读取真值。

下一次验收使用新的Blender场景与冻结视角，至少覆盖斜杆、遮挡、内部亮条、相邻细线、重复背景和真实空缺。必须同时报告正确接受、错误线、空场景假物体、歧义和真杆拒绝。今天的解析评价组已看过，只保留为回归测试。

## 没有声称的内容

这不是普通照片性能提升，也没有修正DA3相机或生成正式补丁。精确相机和解析RGB把问题隔离在候选关联层；跨对象、真实材质及估计相机下的收益仍未证明。
