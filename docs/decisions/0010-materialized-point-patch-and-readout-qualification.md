# ADR 0010：先落实实际补丁，共同读取器必须单独验收

日期：2026-09-22。状态：采纳点快照工程试行协议；两版共同读取器暂不具备主评价资格。

## 问题

此前有限中心线已能输出，但缺少绑定实际基础几何、可撤回、可保存重开的补丁。单独比较新增曲线，又会忽略原始基础中的坏点与错误结构。G1需要完整候选的公平评价，不能仅靠漂亮的新轴线。

## 决定

1. 实现独立版本0.1的materialized-point试行协议，按真实模型像素来源ID保存原点，精确绑定补丁，保留接受与未决证据；不冒充完整depth-backed协议已经落地。
2. 基础和完整候选使用同一固定RGB区域、相同体素尺度与曲线读取流程；新增曲线也先采样成点，不享受直接进入评分的捷径。
3. 读取器必须用完美几何、厚表面、噪声、缺口、多杆等控制单独验证。对候选有利不代表它合格；读取失败、无输出、非空错误长度与尺度变化全部保留。
4. 无支持改动仍保存明确的无修改补丁，完整候选等于基础，进入相同评分。工程拒绝、方法拒绝、读取器失败和几何精度分别报告。

## 证据与代价

7份历史快照约582万点已完成应用、逐字节撤回及保存重开。第一版读取器漏厚/噪声圆杆；第二版虽提高上限，却把一对邻近圆杆读成假中间轴，并暴露数值分段及整分量污染问题。[完整结果](../experiments/2026-09-22-point-patch-and-common-readout.md)保留两版全部评分。

因此，两版均不作为G1通过的唯一证据。后续先处理分段数值稳定性、横截面多峰和局部污染，再冻结新控制。当前新增代码没有推翻9月21日的身份结论，也没有提供不同对象或估计相机下的改善证据。

物化点数组牺牲存储效率换取当前可检查性，未来迁移正式深度契约时需保留同一来源身份与单位。Blender、并发任务生命周期和性能优化继续按后续阶段完成；不为赶进度把未实现内容隐藏在接口名字里。
