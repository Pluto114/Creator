# ADR 0008：圆柱轮廓一致只提供条件性几何证据

日期：2026-09-20。状态：实验分支已实现；未批准为正式目标接受策略。

## 证据与决定

左右两条亮度边缘不能直接当外轮廓。新增模块先用共同轴和半径预测圆柱轮廓，在原图像素上核对两侧；按视角、左右侧分别计分，避免观测长的视角掩盖别的视角。阈值是1px、每侧90%、至少四视角。圆柱、准确相机与像素定位都属于方法假设。

严格要求原支持视角全部通过，会让背景混入的一张图否决正确缺口。实验分支允许一次剔除失败视角，但必须同时退出轴拟合与有限段投票；剩余至少四视角，重拟合后全部复验。没有循环挑子集，没有通过GT选视角。旧严格版保留作对照。

旧开发数据有收益，冻结后的新布局也能保住更多候选。然而新负例n06的邻杆五视角全部几何自洽，仍错收8个重复条件。错误不是丢视角的产物，更不是缺少圆柱公式；输入的粗guide不足以可靠表达目标身份。

因此当前`accepted`只表示限定候选池中的条件性几何解释通过实验检查。不得将它直接解释为物理目标确认、自动发布正式PatchResult或真实表面半径。半径0.010m新例的筛选半径约0.0072m，正说明后者尚未成立。

## 下一步

将目标身份输入、几何支持、有限端点/缺口分别验收。先定义可观察的目标身份约束及其缺失状态，再冻结新数据验证；不能只在已见近杆案例上缩小guide距离阈值。保留多解释与未知状态，不让未确认候选自动改写重建。独立物体、估计相机、实拍及可撤回补丁仍是后续工作。
