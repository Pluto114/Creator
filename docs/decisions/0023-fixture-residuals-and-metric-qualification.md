# ADR 0023：标记残差通过不能单独证明米制细杆精度

日期：2026-09-29。状态：采纳评价约束；默认方法不变，G1 未通过。

## 决定

将当前相机 `validated` 解释为“给定声明 CAD 和零畸变模型下的覆盖/重投影检查通过”。米制长度、外部坐标和端点的可信度还依赖标定物尺寸与位置的独立测量。留出 ID 与训练 ID 共用同一标尺声明，不能排除共享比例或坐标原点偏差。

保留米制长度、端点、曲线误差、段数和真实断口的并列评价。拒绝条件下保留空输出、零正真值恢复率和未定义精度；不把拒绝等同重建正确，也不把空输出的零断口误填当成恢复收益。

## 证据

同批 10 个冻结挑战、3 个旧开发对象、2 法共 60 行；方法和门槛均不变。共享 CAD 尺寸 ±1% 使最细杆长度变化约 ±19.924 mm，留出重投影残差几乎不变。一块板的深度声明误差 20 mm 时，留出 p95 最大值从 1.038 px 降至 1.000 px，而细杆曲线 p95 从 0.465 mm 增至 12.987 mm。整体原点平移主要改变绝对位置，长度基本不变。

缺失训练板、缺失留出标记、训练 ID 互换和正负径向形变均使本批相机流程拒绝；所有拒绝行均未输出细杆。五种仍输出的条件中，真实断杆保护后的 300 mm 缺口均零误填。180 份 pre 收据不变，post 精确复算通过。

## 后续要求

先冻结独立量尺/板间测量与误差预算，明确米制不确定性和拒绝行为；不能用这批目标杆真值反向修正标尺。径向模型改动须使用新的版本和冻结挑战，在同一派生 RGB 上联动相机和细杆验证；不得放宽 2 px 门槛来宣称支持畸变。小畸变、独立对象、实拍、自动身份和共同点云读取器仍待验证。
