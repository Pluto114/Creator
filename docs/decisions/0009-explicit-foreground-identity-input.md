# ADR 0009：用显式前景点表达身份，保留同预算几何对照

日期：2026-09-21。状态：实验实现，G1未通过；不是正式自动补丁策略。

粗guide无法可靠区分近邻真杆。新增两张原图上的前景成员主张，附RGB哈希与定位不确定范围；它们不是同一三维点的对应关系，不改变候选几何。只有有限段和实测带完整支持、且没有尚可能竞争解释时，才条件式接受。缺测、退出视角和部分支持保持unknown，不吸附、不补点击、不填缺口。

额外输入必须公平：普通几何和圆柱筛选收到相同点击，不能把点击提供的信息归功于圆柱方法。旧开发两版各12次正确；新布局普通版13次、圆柱版8次，都是重复设置计数。圆柱使同照片分开双杆可分别选择，却会因退出了标注视角拒绝新缺口和邻杆；普通版在±4px错点下还会输出两杆中间的假轴。两次一致地选错物体，两版也可能接受。

因此保留两条几何路线作可审计对照，不设一个按GT挑最好分支的“联合算法”，不把圆柱当所有场景的总开关。目标成员输入、几何可信度、有限覆盖范围分别记录。`accepted`仍是限定候选池及输入主张下的实验结果，不能直接发布PatchResult，也不保证表面或物理身份。

下一轮先验证独立局部身份观测与几何视图退出的关系，以及跨物体空隙的错误边缘带。若需要用户再点别的图，新增输入成本必须记账。规则先冻结，再测独立对象和估计相机；本次已评分图今后只作回归。不扩插件UI。
