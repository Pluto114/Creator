# ADR 0004：由实测选择基于原图观测的中心线恢复

状态：接受为下一版实现方向；收益尚待独立对象实验。日期：2026-09-14。

2026-09-16实施记录：原图观测、逐段投影支持、目标线LOO和拒绝原型已完成，正式补丁仍未接入。解析测试促使追加逐行采样；真实相机下最细杆改善，但普通估计相机全拒绝，中杆保留视角失败，负反证没有独立增益，背景ORB诊断暂不够可靠。下一步按[实测报告](../experiments/2026-09-16-rod-evidence.md)先测试中心偏置和独立背景约束，以下为原始设计理由与尚未全部落地的目标行为。

## 决定

下一版以“共享全局相机、原图中心线观测、多视图交会、局部证据检查、允许拒绝”为主线。DA3提供全局基底和初始相机；局部杆的几何主要由图像观测估计。保持原基底不变，符合证据的有限线段才进入补丁。

这是经典多视图几何组成的可检验方案，不把TLS、RANSAC或平面交会本身宣称为新算法。研究价值必须来自独立对象上可复核的收益、可靠拒绝和明确的失败边界。

## 为什么这么选

依据是[本轮完整对照](../experiments/2026-09-14-crop-oracle-line-controls.md)，不是看一张最好看的点云。

1. 裁剪提高杆中心点的过滤保留量，却没有稳定恢复位置；居中裁剪也未解决。局部放大适合提取图像观测，不应默默重建一套彼此无关的局部相机。
2. 给真实相机后，砖块最细的默认保留仍仅1.94%；砖块中杆严格点位移仍约14 cm。光修相机或置信阈值不够。
3. 相同原图脊线配真实相机，最细目标位置中位数约4–9 mm；配估计相机差得多。原图确有可用信息，相机质量却是必须检查的条件。
4. 普通TLS和固定RANSAC会跟着错误深度或背景走。它们继续作为基线，不能承担全部局部恢复。
5. 真实缺口在简单三视图位置投票后仍可能被错误补上。连续图像响应不等于同一个三维点被可靠观测。

## 最小实现顺序

以下是拟实现的行为，不是已经完成的模块。

### 1. 固定全局基底与相机，先判断是否够用

复用一次完整图重建快照，局部裁框只记录原图到局部的显式坐标变换。先比较完整图504/756的估计相机与成本；这轮756仅有一个开发条件，不能直接宣布它普遍更准。

相机检查只使用方法允许的输入和非目标背景一致性，不使用GT或待修杆的最佳拟合。记录匹配退化、重投影残差和视图子集稳定性。相机不可靠时返回需要更好观测或no_supported_change；不能靠修杆时移动整个坐标系掩盖误差。

### 2. 从原图条带得到中心与不确定性

暂时保留粗ROI和显式人工跨视图对应，准确报告人工参与。先改当前最容易出错的一步：最大亮暗对比峰不一定是杆中心。尝试左右边缘配对、中点、沿杆方向一致性，并保留候选宽度、位置不确定性、缺测与歧义。

同一图像条带不能自动产出一条“整齐的无限线”。杆端点、遮挡、可能的真实缺口都要保留为局部观测状态。不能为了提高连续性，先在2D把所有空白填上。

### 3. 求候选几何，同时检查它是否解释了观测

用现有平面交会形成候选，再以原图的重投影距离和观测不确定性作鲁棒优化。评估每个视图的残差和视图子集稳定性；方向平行、低视差、跨视图对应有歧义时允许拒绝。

这里的相机保持在共享基底中。若后续加入相机优化，应由独立的非目标背景约束产生，作为显式对照；不能让目标杆与GT一起把相机调到最好看。

### 4. 用正反证据决定每一段保留还是断开

候选线附近有一个高对比像素只算候选响应。有效支持还需要满足重投影位置、边缘方向/宽度和同一目标对应的一致性。

对候选线的每个位置，区分明确杆证据、可见背景反证、遮挡和无法判断。可见背景应该阻止桥接；遮挡不能被当成“肯定有杆”。当前沿线投票、直接min/max连接都保留为失败对照。

最先验收整杆与真实缺口这一对目标：既要恢复应有部分，也要避免把已知可见的空隙填满。误差和错误新增长度始终并列；单看恢复量会奖励瞎补。

### 5. 输出可撤回的局部补丁

输出有限中心线段、逐段证据、拒绝原因和输入快照身份。只用显示半径预览，不宣称恢复了真实杆表面；原点云、照片和预测NPZ不改写。

初版先做离线局部前后对照。插件交互等几何收益和拒绝行为验证后再扩建。

## 下一轮实验如何限制自己

- 同一批输入、ROI、全局相机和评测范围下比较：当前RGB交会、普通/鲁棒深度拟合、候选方法。
- 先在解析相机/杆/真缺口上验证坐标、噪声、遮挡和拒绝；再用独立几何布局和独立对象，不能把同资产换纹理当成泛化。
- 在继续调参数前冻结开发对象、预算与容差。沿用2/5/10 cm诊断并报告完整误差分布；正式目标阈值需结合成像宽度和应用尺度另行冻结。
- 加入未参与选点、拟合或参数选择的保留视图。输入视图一致性检查只能说明自洽，不能充当保留视图证据。
- 位置偏差下降，但错误补全增加，不算通过；没有证据返回不修改，也必须进总表。
- 只有当前两个手工对应目标有效时，结论停留在可行性。共同曲线读取器及完整候选的公平评价仍按架构05实施。

目前到达的是G0中“有证据选择下一版实现”的位置。G1要求的跨对象稳定改善和可靠补丁尚未完成。
