# ADR 0007：粗引导属于目标身份输入，不是几何真值

> 续测状态：新[压力测试](../experiments/2026-09-19-identity-stress-and-finite-segments.md)没有验证这一层的可靠性：0/8px仍错收近邻杆，16px误拒两条正确线。保留其输入语义及诊断用途，不晋升为可靠验收门。

日期：2026-09-19。状态：接受为下一轮候选验收层；参数仍需新保留集验证。

## 依据

[新Blender身份实验](../experiments/2026-09-19-blender-identity-and-guide-guard.md)表明，多视图几何能正确恢复干净、斜向、遮挡和带背景干扰的目标线，也能在相邻双杆与强表面响应中保留歧义。但当目标为空、粗ROI内存在另一根真实杆时，错误杆在五个视角都完全自洽，几何层会稳定接受假目标。

在已看过的解析和Blender案例上，要求三维线投影落在粗guide的身份带内，可以拒绝明显偏离用户目标的背景线，并保住本轮全部正确接受。它仍无法拒绝紧贴目标guide的表面亮条或近邻背景线。这说明guide提供“用户指的是哪一片区域”，没有提供物理轴答案。

## 决定

1. 把每视角粗guide定义为允许的方法输入和目标身份先验。它参与候选验收，但不计为图像算法自动识别出的证据。
2. 几何层先独立输出唯一、歧义或拒绝。guide门只拒绝明显离开目标带的唯一线；不使用guide在多个几何候选中偷偷挑一个赢家。
3. 初始开发参数为观测搜索半宽的四分之一，至少3个视角且至少75%视角同意。该参数只进入新保留集，不宣称已泛化。
4. 报告分别给出几何结果与guide后结果。只要guide门改变判定，就明确标注这是用户先验带来的拒绝。
5. guide通过后仍需物理轴检查。外轮廓/宽度、视角相关表面响应、有限端点和缺口证据不能由guide替代。

## 代价与边界

粗guide过窄会拒绝正确线，过宽又挡不住近邻物体。用户在多个视角画guide也增加交互成本；后续可以研究由一两个确认视角传播，但不能在没有证据时自动伪造对应。

本轮回放使用的20例都已在设计前看过，只证明代码行为和旧正确案例没有立即回退。下一次验收必须冻结新的guide扰动、近邻距离、遮挡比例与独立对象，再给误拒/漏拒曲线。若新保留集不稳定，退回“需要人工确认或保持歧义”，不把阈值硬编码成研究结论。

## 没有声称的内容

这不是表面亮条修复，也不是普通照片准确率提升。它没有恢复有限端点、缺口或网格补丁，没有证明一条guide内的线就是物理中心轴。

## 后续证据边界补充

旧 Blender guide 来自预设三维轴投影，因此上述回放不能证明真人粗标注可靠。新实验必须独立记录 guide 来源，报告提示误差与相机来源；固定屏幕坐标仍是合成引导。用户输入可以约束身份，但自动从几何答案生成的先验不能被包装成用户提供的真实信息。
