# 0019：把对应、目标身份和三维精度分开验，不用模型排名直接出轴

日期：2026-09-26。状态：研究决定；G1未通过，默认方法不变。

## 证据与决定

20个配对种子确认端点跨图留出可以排除给定的单图交换，但不能排除全视图一致认错；额外正确目标声明可以拒绝这批一致错目标，跟着候选一起错的声明仍会通过。正常对应20个控制也都通过，三维p95却为4.14–42.36mm，平均恢复率79.07%。因此“像素相容”不能升格为目标正确或三维准确。

采用职责分离的检查原型：背景轨迹负责相机候选；给定端点留一视图重投影负责对应矛盾；额外目标声明只检查有限段是否相容。目标声明不重拟合几何，不修改候选排序，不连接缺口；相机扣留与缺失几何不能被新检查提升。有效矛盾可以拒绝，证据不足保留未决。当前2px和两目标视图预算是固定研究假设，不是校准后的准确率承诺。

7组旧RGB/DA3的70行回放中，原51个eligible全部保留，含27个双向p95≤25mm和24个超出条件。这说明复用已经参与目标选择的点击没有新增筛错能力。旧观测不能换个字段名就成为独立验证；后续额外证据必须在拟合和选择之前明确冻结来源、获取方式及使用范围。

解析实验的端点身份、共线结构与目标点生成方式均是给定条件，初始相机为预声明扰动，不冒充RGB检测或DA3输出。20种子是重复单位；400行几何/4800决策相互关联。每组只用控制相机对齐一次，拒绝/未决的空正例R=0、P未定义，所有fold都报告。

## 读取器设计保持未决

64个新截面条件证明保留格内原始位置有可用信号，但更灵活模型的低残差不能证明多杆：半椭圆、圆、平面和薄片均有反例。双圆还允许相交，椭圆会退化得很扁，未收敛和参数边界不能隐藏。

这次三模型比较不输出轴、不增加放行门。所有点共享坐标架、分位边界、搜索范围与权重，部分raw训练/评价点还占同一体素，因此仅为共享预处理下的模型参数留出。下一版先冻结按体素分组、间隔与训练侧坐标架的控制，再检验复杂度、物理重叠、未观测表面及可辨识性。缺点不等于自由空间，不能凭补全得漂亮就认定封闭杆面。

## 下一阶段交付

2. 新版截面控制只改观测表示与验证隔离，先保留所有模型和未决，不在已评分64条件上挑新门槛。
