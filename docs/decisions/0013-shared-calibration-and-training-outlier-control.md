# ADR 0013：固定镜头条件下验证共享标定与两阶段错配处理

日期：2026-09-23。状态：采纳下一轮候选方法；未成为可自动应用的校正。

## 依据

实际DA3初始化、同一已知双深度解析RGB，第一轮8项优化未通过预定检查。延长原每视图K比例模型的预算，虽改善保留像素误差，三维点中位误差仍约529mm。

显式假定固定镜头/方形像素、共同优化一个焦距和位姿后，两阶段方法把保留像素中位误差5.423px降到约0.208px，相机中心RMSE47.78mm降到1.78mm，保留点三维中位497.14mm降到28.90mm。训练中注入47条错配时，先soft-L1拟合、按训练支持剔除再拟合的结果接近；仅soft-L1仍明显偏位。

这些是一个开发布局的实测结果。约29mm点误差不是杆轴精度，也未完成独立物体复验。两项三维仍差的候选通过了像素检查，说明该检查不能独自决定发布。完整数据见[报告](../experiments/2026-09-23-camera-bundle-and-fixed-lens.md)。

## 决定

1. 下一轮固定使用共享焦距、训练阶段两次拟合的候选，保留未校正、普通拟合、单次soft-L1等配对对照。配置冻结后在新场景评价，不回写本轮分数。
2. 固定镜头/方形像素是明确的采集假设；不得把真实K放进优化，不得静默用于变焦、混相机或变化裁剪。需要单独检验假设不成立的条件。
3. 训练删除规则不读GT或错配注入清单。保留所有被删轨迹和独立验证分母，不用删除后的低训练误差冒充全体改善。
4. 不把RGB检查通过等同于厘米级物理可靠。候选相机继续与正式基础隔离；接入时必须生成相机/深度/点身份一致的新几何版本，不能重标旧点。
5. 接下来进入具备可用参考观测的新杆数据，检验轴、端点与缺口收益，再做共同读取器及独立对象验收。采集条件变化单独报告，G1不降低门槛。
