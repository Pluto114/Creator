# ADR 0014：先验证残余位姿，再决定是否改杆端点

日期：2026-09-23。状态：采纳下一轮实验顺序，未批准自动应用校正。

## 证据

新参考纹理Blender数据上，冻结共享焦距两阶段法在完整杆取得R/P100%、曲线p95约8–10mm。断杆仅82.3%/84.0%，细杆67.6%/68.3%；断杆仍两段但整体偏移，缺口保护内部容差覆盖19.9%。三者像素候选检查均通过，不能作为物理验收。

评价侧独立替换实验中，只换真实位姿，断杆和细杆均R/P100%，p95约4–5mm，断杆缺口保护内部覆盖0%。只换真实K没有解决问题。相同观测池及端点规则在完整真实相机下p95约0.8–1.7mm。见[完整报告](../experiments/2026-09-23-reference-assisted-rods.md)。

## 决定

1. 优先验证残余位姿精度。下一轮对比同高度和有高度变化的拍摄路径，方法和参数先冻结；把这是采集条件变化说清楚。近同高度路径可能放大残余姿态偏差只是待验证假设。
2. 保持现有端点/缺口规则作为配对基线；本轮不通过放宽25mm容差或缩小缺口保护区获得“通过”。
3. 保留普通、鲁棒、两阶段三项。断杆普通拟合部分指标优于两阶段，不能事后换主方法或笼统声称鲁棒更好。
4. 固定镜头是适用条件。变焦反例被候选门扣留，但一次拒绝不是通用失配检测保证；相机候选仍不自动发布。
5. 所有oracle只存在于评价侧。后续接基础时创建相机/深度/点身份一致的新版本，不把旧点云换个相机标签。
6. 本轮只有三种程序化圆柱布局，没有独立物体、实拍或合格共同读取器证据。G1保持未通过。
