# 0020：新增视图仍会继承旧地图偏差，局部点击不能验收整根杆

日期：2026-09-26。状态：研究决定；G1未通过，正常默认方法不变。

## 新证据改变了什么

三个旧布局各新增两张RGB，六个目标成员点在新定位和投影前冻结。五条件/两条旧采集路径给出30份固定地图，背景PnP得到60个新相机，目标点从不参与定位。60个背景验证全部通过，原51个eligible杆也全部保留，其中24个仍有至少一向曲线p95>25mm。新增图像有独立的观测身份，但其定位和三维验证点仍来自同一旧相机地图，不能称独立绝对标定。

随后另冻的评价侧四臂诊断固定旧control Sim3和杆，只替换新相机K/位姿。真K+真位姿下，27个原25mm读数达标者为23支持/4未决；24个超差者为8支持/14未决/2矛盾。只换K反而使16个达标者未决，却保留全部超差。K与位姿误差存在补偿关系；不能把单个像素门或局部点击当整根三维准确性证书。该诊断是正常结果之后提出的事后分析，使用特权真值，不能进入正常修复流程。

## 后续算法约束

保持旧地图和杆不变的新视图检查，作为附加观测诊断保存，不发布新的自动接受策略。2px规则未标定成25mm曲线精度，成员点击也不是跨图物理端点。新证据不足、定位不足、未收敛都保留未决和空输出代价，不能提升旧拒绝。

下一阶段把可测量的独立标定信息和沿杆分布的有限结构观测列为两项明确输入：前者约束相机/尺度与共同偏差，后者覆盖端点、长度及缺口。新增标定板尺寸、坐标或镜头标定必须来自声明的采集条件与正常观测文件，不能复制隔离的GT。先冻结协议和误差代价，再运行；当前已评分图像只作开发材料。

不继续以同一个候选的重投影自洽，替代完整基础/候选共同曲线评分。更严格的目标门必须同时报告超差漏放与达标误扣，不能只报拒绝多了多少。独立对象、实拍和真正物理收益仍是后续验收项。

## 读取器验证边界

截面新版本按固定原生体素分组、留guard，训练中心/PCA/搜索范围/权重只从训练点建立，128fold零共享格。旧64开发条件仍有完整椭圆/双杆信号，也仍有半面、圆和薄片反例，因此没有新的自动出轴或模型选择门。

固定原生z窗使用了已知布局先验，不宣称旋转/平移通用。新旧划分同时改变子集、guard和训练跨度，差值不是单因素因果效果。r1只修干净CI的夹具来源与运行身份，方法结果与保留v1一致，不重复计算样本量。
