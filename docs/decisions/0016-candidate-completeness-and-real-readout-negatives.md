# ADR 0016：把候选完整性和实际点云负例放到冲刺主线上

日期：2026-09-23。状态：采纳实验顺序；本轮新方法不替代默认或验收口径。

本轮三个并行任务给出一致提醒：局部好指标不能代替完整的几何证据。候选重拟合没有改善细杆，并让新断杆退回未决；保留近邻像素赋值揭示此前隐藏的身份解释。全视图背景验证补上两端相机评分，却仍在0.677px p95下留下约30mm细杆偏差。新读取器解析控制189/198→197/198，实际DA3点云却有精确率退步。

1. 不推广主重拟合、行覆盖排序或保守赋值保留为新默认。先研究观测支持与近邻解释的等价/不确定性，不能用几何距离去重后宣称物理身份唯一，也不能简单选支持行最多者。
2. 相机诊断保留原主评分，新增全视图验证只补覆盖。下一实验固定训练轨迹分组与验证计划，报告杆位姿敏感性分布，不用GT挑一次最好解。
3. 第四版读取器继续作为研究对照。后续优先未用于设计的非杆背景、局部污染和真实模型区域，保持旧解析评分与缺口指标；不按哪版分数漂亮选评价器。
4. 正常推理/评价隔离、旧实验不覆盖、先冻结后跑。所有新相机和补丁仍是研究版本；正式深度契约及界面后置。
5. G1未通过。9月27日按未决项逐项检查，若核心几何/评价仍未达标则继续保留失败，不降低验收标准或拿条件数抵独立对象数。
