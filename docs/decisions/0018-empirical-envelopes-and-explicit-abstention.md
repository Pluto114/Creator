# 0018：经验范围不能代替物理正确，拆分不足不回退假中轴

日期：2026-09-24。状态：研究决定；G1未通过，默认方法不变。

## 为什么做这一步

上一轮相机留组实验里，杆像素的赋值与支持行完全不变，细杆三维分数却大幅变动。另一方面，读取器对没有充分分隔证据的组件回退整体拟合，会把真双杆压成一条假中轴。两个问题都不能靠给“接受”换个名字解决。

## 决定

完整训练保持控制结果，四个预先固定的64px训练删组只用于描述变化。新范围模块始终保留五个槽位；相机扣留、杆身份拒绝、像素支持改变、规范坐标不同或有限段拓扑无法一一对应，都会使完整范围不可用或未决。不得删掉不好看的fold，不取最佳fold，不平均回写控制杆。

有限段按控制轴的正区间交叠做一一对应，保留段数、顺序和正缺口。每段33个固定比例位置在同一个控制局部坐标架记录最小/最大位移，同时保留端点、长度、方向和缺口变化。数值结构容差只判断能否比较；范围窄从来不构成通过物理验收的门槛。这是已观察到的扰动范围，不是置信区间，也不是误差上界。

评价只用完整控制相机中心估计一个Sim3，并把这个变换固定用于整组。杆真值不能参与对齐或拟合，四个扰动不能各自重新对齐来消掉漂移。真值包含比例是每段33个同比例点的等段权计数，另外保留弧长加权曲线R/P和两个方向的距离；两种量不能互相冒充。

新增16个解析像素挑战在拟合前冻结。其中的端点跨图身份与共线假设是明确给定的，初始相机来自预声明的真相机扰动，不能称为DA3预测或RGB检测效果。它们用于测试机制及“稳定但错”的盲区；各条件不同随机种子，不能单凭本轮差别归因于噪声或深度。未见对象和实拍仍需另做。

读取器采用独立未决版本：已有有效二分提议，却缺少分隔证据时，这个组件保留未决，停止生成整体中轴；有可靠输出的其他组件照常保留。拆分预算耗尽也不能触发假中轴回退。参数沿用closed版，不依照本轮分数调整。`complete`只表示程序跑完，`resolved/partial/unresolved/no_supported_curve`单独记录；resolved也不是正确性标签。

## 代价与下一步

读取器旧198指标仍194通过；新正例10→9/16，新的负例零假曲线达到8/8，但其中4例是未决。漏检仍是失败，不因为保守就获得加分。实际DA3回放在100mm容差下还有三项召回下降，完整保留。

下一步先固定少量代表机制，使用多种子且同场景同噪声的成对实验区分偏差与扰动幅度；不要在今天这16案上挑一个“看着安全”的宽度门槛。几何本身无法区分同样观测下的错目标，需要额外可观测证据。共同读取器还需要能区分椭圆单杆和近邻多杆的资格测试，再接独立对象、估计相机和真实采集。正式深度契约与研究复现材料继续保留为未完成项。
