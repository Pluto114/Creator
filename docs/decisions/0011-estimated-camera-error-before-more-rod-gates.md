# ADR 0011：先处理估计相机误差，不继续堆杆筛选门槛

日期：2026-09-22。状态：采纳下一轮实验优先级，校正算法尚未实现。

## 依据

前景身份方法在同4个已知布局、相同RGB观测和点击下接入DA3估计相机。普通方法两个接受结果都偏轴约19–24cm；圆柱版全拒。相机中心对齐残差不足跨度1%，仍不能保证局部杆准确。

仅评价侧固定替换真实内参、位姿或两者：只换K没有正确输出；只换位姿出现普通3正确/1错误、圆柱2正确/0错误；两者都换为普通4正确、圆柱2正确。全部真实相机条件与之前相同设置的18项状态和核心曲线指标一致。详见[报告](../experiments/2026-09-22-readout-split-and-estimated-cameras.md)。

## 决定

1. 下一轮优先验证共享相机位姿及内参误差的处理。现有几何门槛基本按相机可信设计，不能用继续放宽投影门槛掩盖系统偏移。
2. 新校正必须只依赖允许的RGB/模型观测，明确约束来源与退化条件。同输入预算的简单对照、原始相机结果、未校正失败一并保留。仅在评价侧使用的oracle不得伪装为可部署校正。
3. 相机变化必须形成新身份的几何输入和快照；不能用新相机解释旧点坐标而不给出一致的变换或重新物化过程。深度、相机、点ID和补丁绑定继续追踪。
4. 第三版共同读取器已修已知假断裂和双杆反例，但半边表面、杂点、交叉杆和宽度上限仍未解决。完整候选评分资格继续作为独立验收项，不能改用新增曲线成绩绕过。

这是由受控替换支持的优先级调整，不是相机校正已经有效的结论。独立对象与无GT估计相机收益仍为空白，G1继续未通过。
